# Доклад и сценарии за тестове по сигурността (Security Testing & Vulnerability Prevention)

Този документ описва тестовите сценарии и мерките за предотвратяване на IDOR, XSS и SQL инжекции в UniCloud, съгласно изискванията на MVP.

---

## 1. Защита и тестове срещу IDOR / BOLA (Insecure Direct Object Reference)
* **Концепция:** Всеки endpoint на Backend-а, който извлича или променя ресурс по идентификатор (напр. `/api/materials/{id}` или `/api/statuses/{userId}`), задължително проверява дали текущо улогиваният потребител има права върху този ресурс.
* **Тестов сценарий:** Студент с ID `2` прави `GET` или `PUT` заявка към ресурс, който принадлежи на студент с ID `1`. 
* **Очакван резултат:** Сървърът отказва достъп и връща грешка **403 Forbidden** или **404 Not Found** (ако ресурсът е скрит).

---

## 2. Защита и тестове срещу XSS (Cross-Site Scripting)
* **Концепция:** Потребителският вход (например описание на курс, заглавие или коментари) се филтрира, екранира и не се изпълнява директно в браузъра като суров HTML/JavaScript.
* **Тестов сценарий:** При опит за въвеждане на злонамерен скрипт в полето за описание (напр. `<script>alert('XSS')</script>`), данните се записват като обикновен текст или се пречистват (Sanitization).
* **Очакван резултат:** Браузърът извежда съдържанието като текстов низ, без да изпълнява скрипта.

---

## 3. Защита срещу SQL инжекции (SQL Injection)
* **Концепция:** Забранено е директното слепване на стрингове (string concatenation) при изграждане на заявки към базата данни.
* **Реализация в UniCloud:** Използва се **Spring Data JPA / Hibernate (ORM)**, което автоматично прилага параметризирани заявки (PreparedStatement) за всички операции.
* **Тестов сценарий:** Вмъкване на SQL оператори (напр. `' OR '1'='1`) в полетата за търсене или вход.
* **Очакван резултат:** Базата данни третира входните данни строго като стойност, а не като изпълним SQL код, предотвратявайки заобикалянето на автентикацията или извличането на данни.

---

## 4. Критерий за приемане (Acceptance Criteria)
* Документирани са тестовите сценарии за IDOR, XSS и SQL инжекции.
* Описани са мерките за сигурност, които се интегрират съвместно със софтуерните инженери в кода на Backend-а.
