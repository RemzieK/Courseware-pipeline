# Проверки за сигурност в CI/CD Pipeline (Security Checks in CI)

Този документ описва автоматизираните проверки за сигурност, конфигурирани в `.github/workflows/security-ci.yml` за проекта UniCloud.

---

## 1. Интегрирани инструменти за сигурност в CI

1. **Secret Scanning (Gitleaks):**
   * **Предназначение:** Сканира кода и Git историята за случайно записани пароли, API ключове и токени.
   * **Поведение:** При откриване на секрет pipeline-ът спира и блокира сливането.

2. **Trivy (Container & Config Scanner):**
   * **Предназначение:** Сканира Docker файловете, базовите образи и конфигурационните файлове за известни уязвимости (CVE).
   * **Поведение:** Конфигуриран е с `exit-code: 1` за ниво `CRITICAL` — при критична уязвимост pipeline-ът пада автоматично.

3. **OWASP Dependency-Check:**
   * **Предназначение:** Проверява Java/Maven/Gradle зависимостите на Backend услугата (`backend/unicloud`) за уязвими библиотеки.
   * **Поведение:** Активира се автоматично при наличие на Backend проект и прекратява build-а при критична уязвимост (`CVSS >= 9.0`).

4. **OWASP ZAP (Passive Scan):**
   * **Предназначение:** Извършва пасивно динамично сканиране на уеб приложението след стартиране на тестовата среда (съвместно с DevOps след изпълнение на UC-23).

---

## 2. Критерий за приемане
* Pipeline-ът автоматично пада при откриване на критична уязвимост (`CRITICAL`) или изтекъл секрет.
