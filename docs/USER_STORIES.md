# USER_STORIES – UniCloud, Екип 2

Формат: **Като** <роля> **искам** <действие>, **за да** <полза>.
Приоритети: **P0** – нужно за демото на Седмица 1; **P1** – важно, след P0; **P2** – следващи седмици.
Подробните критерии за приемане са в `ACCEPTANCE_CRITERIA.md`; тук е само кратката проверка.

## Роли

| Роля | Описание |
| --- | --- |
| Преподавател | създава курсове и публикува материали |
| Студент | разглежда, търси и чете материали |
| Администратор | управлява акаунти и роли (временни демо акаунти в Седмица 1) |
| Декан / Академичен съвет | следи показателите и гаранциите |
| Друг екип (1, 3, 4) | системите, които ще се свързват с UniCloud |
