# USER_STORIES – UniCloud, Екип 2

Формат: **Като** <роля> **искам** <действие>, **за да** <полза>.
Приоритети: **P0** – нужно за демото на Седмица 1; **P1** – важно, след P0; **P2** – следващи седмици.
Подробните критерии за приемане са в `ACCEPTANCE_CRITERIA.md`; тук е само кратката проверка.

## Роли

| Роля | Описание |
| --- | --- |
| Преподавател (`TEACHER`) | създава курсове и публикува материали, управлява собствените си ресурси |
| Студент (`STUDENT`) | разглежда, търси и чете материали, управлява личните си отметки за напредък |
| Администратор (`ADMIN`) | управлява всички ресурси и системни настройки |
| Сервизен акаунт (`SERVICE`) | ограничен машинен достъп за интеграцията с автоматичното оценяване (Екип 3) |
